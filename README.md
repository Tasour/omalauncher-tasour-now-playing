# omalauncher-tasour-now-playing

Widget OWL « lecture en cours » pour [omalauncher](https://github.com/SimonSchubert/omalauncher) : pochette, titre, artiste, album, progression et commandes lecture/pause/suivant depuis n'importe quelle application musicale ou podcast du téléphone. Un tap ouvre l'application.

## Installation

```sh
cp market-simonschubert-now-playing.owl ~/.config/omalauncher/widgets/
owl-check ~/.config/omalauncher/widgets/market-simonschubert-now-playing.owl
```

L'accès aux notifications doit être autorisé pour qu'omalauncher voie les sessions média des autres applications. Aucun paquet supplémentaire requis.
